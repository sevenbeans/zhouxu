## 三类页面状态

| 状态 | 代表样本 | 产品行为 |
| --- | --- | --- |
| 明确日期 | IMG-01 | 可生成日期范围草稿，仍需保留原文依据 |
| 只有发布时间 | IMG-02 | 记录发布时间，不生成截止日 |
| 完全无日期 | IMG-03 | 显示缺失，不写入日历 |

这三种状态比“所有页面都能识别出截止日期”更接近真实招聘页面。评测时应把“没有生成错误日期”算作正确行为。

## 现有样本缺口

3 张样本不足以评估 OCR 稳定性。至少还需要：

| 类型 | 目标数量 | 当前数量 |
| --- | ---: | ---: |
| 企业招聘网页 | 6 | 3 |
| 公众号 / 群聊长图 | 3 | 0 |
| 笔试或面试通知 | 3 | 0 |
| 课程或实习通知 | 2 | 0 |
| 模糊或异常日期 | 2 | IMG-01 可提供日期范围，仍缺模糊表达 |

优先补充的真实样本：

- “即日起”“招满即止”“截止时间待定”
- “本周五”“3 天后”等依赖发布日期的相对时间
- 多页岗位公告，日期不在首屏
- 笔试两个时间冲突的通知
- 图片压缩、模糊、截断、遮挡后的页面

## 不能自动获取的素材

以下内容属于登录后才可见或个人账号信息，不能从公开网页稳定获取：

- 投递状态页
- 笔试 / 面试邮件
- 微信群或朋友圈公告
- 课程系统作业页
- 实习任务聊天记录

这些样本需要用户提供并脱敏，不能用岗位整理 Markdown 代替。
